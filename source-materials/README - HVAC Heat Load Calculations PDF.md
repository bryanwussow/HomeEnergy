# HVAC Heat Load Calculations.pdf

`HVAC Heat Load Calculations.pdf` (the original 1999 Manual J heat load calculation, `HVAC-Calc 3.0`) is present in this folder as of 2026-08-18. It's a scanned/image-based PDF with no embedded text layer, so Claude Code reads it via its PDF vision capability rather than text extraction — no separate Markdown text-extract of this one was created (unlike the other source PDFs in this folder).

Key figures from this file are summarized in `hvac-summary.md` → Section 2 (Load Calculation), including the whole-building vs. per-zone (Main Floor / Basement West / Basement East / Attic Loft) breakdown and how it reconciles against the 2026 Assessment report's load estimate.
